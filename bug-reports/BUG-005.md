# BGMI-005 — “Feature Not Available” Message Displayed Despite Feature Being Accessible

**Severity:** Minor
**Priority:** Medium
**Category:** UI / Events
**Type:** UI / Functional
**Status:** Reported / Requires Verification
**Reproducibility:** Intermittent

## Environment

* **Game:** BGMI (Battlegrounds Mobile India)
* **Platform:** Mobile
* **Feature:** Event / Feature access

## Description

The game may display a “Feature not available” message even though the relevant feature can still be accessed after proceeding past the message.

## Preconditions

* The relevant event or feature is available in the current game version.
* The player can access the relevant feature.

## Steps to Reproduce

1. Launch BGMI.
2. Navigate to the relevant event or feature.
3. Select the feature.
4. Observe the message displayed.
5. Proceed past the message if possible.
6. Check whether the feature can still be accessed.

## Expected Result

The game should accurately indicate the availability of the feature. If the feature is available, it should open normally without displaying a contradictory availability message.

## Actual Result

A “Feature not available” message may be displayed even though the feature remains accessible after proceeding.

## Reproducibility

**Intermittent — requires verification.**

## Impact

The contradictory message can confuse players and create uncertainty about whether the feature is actually available. It may also make the game appear to have an availability or synchronization problem.

## Severity Rationale

**Minor:** The issue primarily affects UI accuracy and user understanding, while the feature itself may remain accessible.

## Priority Rationale

**Medium:** Although the issue does not directly block core gameplay, inaccurate UI messaging can negatively affect the user experience.

## Notes

Further testing should determine whether the message is triggered by event loading, delayed server synchronization, navigation timing, or another UI state transition.
