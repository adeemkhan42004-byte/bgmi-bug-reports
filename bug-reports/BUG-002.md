# BGMI-002 — Displayed Network Ping Does Not Accurately Reflect Network Performance

**Severity:** Major
**Priority:** High
**Category:** Network / UI
**Type:** Functional
**Status:** Reported / Requires Verification
**Reproducibility:** Intermittent

## Environment

* **Game:** BGMI (Battlegrounds Mobile India)
* **Platform:** Mobile
* **Game Mode:** In-match gameplay
* **Network:** Stable internet connection

## Description

The network ping displayed by the game may not accurately correspond to the network performance experienced during gameplay. The displayed latency value can appear inconsistent with the responsiveness observed by the player.

## Preconditions

* The player is connected to a stable internet connection.
* The player is inside an active BGMI match.

## Steps to Reproduce

1. Launch BGMI.
2. Enter an active match.
3. Monitor the network ping displayed by the game.
4. Observe gameplay responsiveness while the displayed ping is being monitored.
5. Compare the displayed ping with the network responsiveness experienced during gameplay.
6. Repeat the observation under different gameplay conditions.

## Expected Result

The displayed ping should provide an accurate representation of the player's current network latency and should reasonably correspond with observed network responsiveness.

## Actual Result

The displayed ping may not correspond with the actual network performance experienced during gameplay.

## Reproducibility

**Intermittent — requires controlled testing.**

## Impact

Incorrect network information can make it difficult for players to determine whether gameplay issues are caused by network latency. This may also make troubleshooting network-related gameplay problems more difficult.

## Severity Rationale

**Major:** The issue affects the accuracy of information used by players to understand network conditions during gameplay.

## Priority Rationale

**High:** Accurate network information is important for diagnosing latency-related gameplay problems.

## Notes
