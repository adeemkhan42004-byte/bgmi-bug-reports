# BGMI-004 — Service Error Occurs When Attempting to Exchange an Event Card

**Severity:** Major
**Priority:** Medium
**Category:** Events / Social Features
**Type:** Functional
**Status:** Reported / Requires Verification
**Reproducibility:** Intermittent

## Environment

* **Game:** BGMI (Battlegrounds Mobile India)
* **Platform:** Mobile
* **Feature:** Event card exchange

## Description

An eligible event card exchange may fail with a service error when the player attempts to send or exchange the card with another player.

## Preconditions

* An active card-collection event is available.
* The player possesses an eligible card.
* The card is available for exchange.

## Steps to Reproduce

1. Launch BGMI.
2. Open the relevant card-collection event.
3. Select an eligible card.
4. Select the option to send or exchange the card.
5. Confirm the exchange.
6. Observe the result.

## Expected Result

The exchange should complete successfully, and the eligible card should be transferred to the intended recipient.

## Actual Result

A service error may be displayed, preventing the card exchange from completing.

## Reproducibility

**Intermittent — requires verification.**

## Impact

Players may be unable to use an intended event feature or transfer eligible items to another player. This can interfere with event progression and social functionality.

## Severity Rationale

**Major:** The issue prevents a specific functional feature from completing successfully.

## Priority Rationale

**Medium:** The problem affects an event feature but does not prevent the player from accessing core gameplay.
