# BGMI-001 — Virtual Joystick Becomes Unresponsive During Gameplay

**Severity:** High
**Priority:** High
**Category:** Gameplay / Controls
**Type:** Functional
**Status:** Reported / Requires Verification
**Reproducibility:** Intermittent

## Environment

* **Game:** BGMI (Battlegrounds Mobile India)
* **Platform:** Mobile
* **Game Mode:** In-match gameplay
* **Input Method:** Virtual joystick

## Description

During gameplay, the virtual movement joystick may become temporarily unresponsive. When this occurs, movement input from the joystick does not produce the expected character movement.

## Preconditions

* The player is inside an active BGMI match.
* The player is using the virtual joystick for character movement.

## Steps to Reproduce

1. Launch BGMI.
2. Start a match.
3. Move the character normally using the virtual joystick.
4. Engage in combat or perform movement actions.
5. Continue using the virtual joystick for movement.
6. Observe the character's response to joystick input.

## Expected Result

The character should respond immediately and consistently to virtual joystick input throughout gameplay.

## Actual Result

The virtual joystick may temporarily become unresponsive, preventing the character from moving despite movement input being provided.

## Reproducibility

**Intermittent — requires further controlled reproduction.**

The issue does not necessarily occur during every match or every attempt.

## Impact

The issue can prevent the player from moving during active gameplay. In combat situations, even a temporary loss of movement control can negatively affect the player's ability to evade attacks, reposition, or respond to opponents.

## Severity Rationale

**High:** The issue affects a core gameplay control and can directly interfere with player movement during an active match.

## Priority Rationale

**High:** Movement is a fundamental gameplay function, and failures during combat can have an immediate impact on the player's experience.
